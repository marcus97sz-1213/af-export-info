AF Data Export

AF Data Export is a personal data analysis tool maintained by Marcus. It exports timestamped gym occupancy estimates from a Cloudflare D1 database into daily Parquet files.

With the account owner's permission, the exporter creates an export folder in Google Drive and uploads or updates its files. These files can be synced to a computer and analysed using Power BI.

Google Drive access

The application requests the drive.file permission. It uses this permission to manage its export folder and files, without requesting access to the entire Drive.
