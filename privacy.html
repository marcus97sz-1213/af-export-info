Privacy Policy

AF Data Export · Updated 13 September 2026

Purpose

AF Data Export is maintained by Marcus for personal gym occupancy analysis. It exports database readings to Google Drive for use in tools such as Power BI.

Data accessed and used

The exporter processes gym identifiers, timestamps and estimated occupancy counts stored in Cloudflare D1. The exported records do not contain individual gym members' names or membership details.

Google Drive access uses the drive.file permission. The application creates its export folder, lists relevant file metadata, and uploads or updates its Parquet files. It does not request unrestricted access to Google Drive.

Storage and processing

Source readings are stored in Cloudflare D1. Export jobs run on GitHub Actions, where data is processed temporarily. Exported files are stored in the owner's Google Drive and may be synced to the owner's computer.

Google OAuth credentials and the Cloudflare API token are stored as GitHub Actions secrets for the private exporter repository. Credentials must not be committed to repository files or included in application logs.

Sharing

Data is processed through Cloudflare, GitHub and Google as needed to operate the workflow. The application does not intentionally publish exported files, sell Google user data, or use it for advertising or AI model training. Files remain subject to the owner's Drive sharing settings.

Retention and deletion

Database readings and exported files remain until the owner deletes them or configures a retention policy. Deleting a Drive export does not delete the original database readings. An active export job may recreate deleted exports.

To stop processing, disable the GitHub Actions workflow. Google access can be revoked through the Google Account connections page. Revoking access does not automatically delete existing files, database records or local copies.

Contact and changes

Contact the developer using the support email displayed on the application's Google consent screen. Changes to this policy will be published on this page with an updated date.
